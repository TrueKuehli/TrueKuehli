# 💙 Welcome to my GitHub page!

👋 Hi there! I'm a PhD student under the supervision of [Prof. Dr.-Ing. Marcus Magnor](https://graphics.tu-bs.de/people/magnor) at the [Computer Graphics Lab](https://graphics.tu-bs.de/) of the TU Braunschweig. My research focuses primarily on Novel View Synthesis and Perception. 

🌐 Here on my GitHub page, you can find mostly hobby projects I've worked on over the years. For research code related to my projects at the Computer Graphics Lab, please check out the [NeRFICG project](https://github.com/nerficg-project)!
